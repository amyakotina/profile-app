# Проект «Профиль» — приложение под тесты

Небольшое приложение для итогового задания по автоматизации тестирования.
В проекте реализованы API-тесты и UI-тесты для проверки авторизации, заполнения анкеты и работы с профилем пользователя. Внутри — вход по e-mail (код приходит в ответе бэка), обязательная анкета и профиль с редактированием.

## Как запустить

```bash
python3 -m venv venv
source venv/bin/activate        
# Windows: venv\Scripts\activate

pip install -r requirements.txt
python app.py
# открыть http://localhost:5001
```

Для тестов (в отдельном окружении/терминале):

```bash
Запустить все тесты: pytest -v
Только UI-тесты: pytest tests/ui_test.py -v
Только API-тесты: pytest tests/api_test.py -v
```

## Как работает

Сценарий пользователя:

1. вводит e-mail → бэк «отправляет» код (в демо код возвращается в ответе и показывается на странице);
2. вводит код → получает доступ;
3. заполняет **анкету** (имя, фамилия, возраст, город, о себе) — без неё профиль недоступен;
4. попадает в **профиль**, где данные можно **редактировать**.

Приложение одновременно отдаёт JSON API (`/api/...`) и HTML-страницы, поэтому к
нему пишут и API-, и UI-тесты.

## Что покрывают API-тесты

**Авторизация**
- запрос кода на корректный e-mail — `200`, в ответе есть `code`;
- запрос кода на некорректный e-mail — `400`;
- верификация с правильным кодом — `200`, приходит `token`;
- верификация с неправильным кодом — `400`.

**Анкета**
- профиль до анкеты — `403`;
- успешное заполнение — `201`, данные сохранились;
- валидация: пустые обязательные поля и некорректный возраст — `400`
  (используйте параметризацию).

**Профиль**
- получение профиля с токеном — `200`, корректные поля;
- запрос без токена — `401`;
- редактирование поля (например, города) — `200`, значение изменилось.

Для проверки разных вариантов входных данных используется параметризация pytest.

## Что покрывают UI-тесты

С помощью Playwright проверяются:

1. полный happy-path: авторизация → анкета → профиль;
2. невозможность попасть в профиль без заполненной анкеты;
3. отображение данных пользователя;
4. редактирование профиля;
5. отображение изменённых данных;
6. выход из профиля.
